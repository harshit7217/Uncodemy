## About

**UnCodeMy** is an ongoing platform project focused on helping individuals recover and 
advance their careers after a layoff. It brings together career-recovery resources, 
job-market insights, and practical tools in one place, with the goal of helping users 
navigate today's job market, sharpen their skills, and land their next opportunity.

### What's in this repo
- **Employee Profile Demo** — a live demo showcasing an employee/profile management page 
  ([view demo](https://employeeprofilee.netlify.app/))
- **Blog content** — career, job-market, and salary-related articles and write-ups 
  (`blog/`, `blog_updated_fixed/`, and related folders)
- **Experimental/working folders** — daily or dated work-in-progress folders (e.g. `3rd-sep`) 
  as features and content get iterated on

### Status
This project is actively being developed — expect frequent changes, restructuring, and new 
additions as features, content, and demos are built out.
