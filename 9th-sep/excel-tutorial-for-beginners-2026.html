SECTION 02Excel Basics

Here are the basic concepts every Excel beginner must know:

Concept What It Is How to Use It
Cells Individual boxes where you enter data Click a cell and start typing
Rows & Columns Rows (numbers), Columns (letters) Navigate using row/column references
Sheets Multiple tabs in a workbook Add, rename, delete sheets
Formatting Change colors, fonts, borders Use the Home tab to format cells
Sort & Filter Organize and filter data Use Data tab → Sort & Filter 
Excel Basics: Navigation & Data Entry

1. Moving Around:
   - Arrow keys: move between cells
   - Ctrl + Arrow: jump to edges
   - Ctrl + Home: go to A1
   - Ctrl + End: go to last cell

2. Entering Data:
   - Click cell → type → Enter
   - Use Tab to move right
   - Use Shift+Tab to move left

3. Selecting Cells:
   - Click and drag for multiple cells
   - Shift + Click: select range
   - Ctrl + Click: select non-adjacent cells
   - Ctrl + A: select all

4. Basic Formatting:
   - Bold: Ctrl + B
   - Italic: Ctrl + I
   - Underline: Ctrl + U
   - Font size: Home tab
   - Cell color: Fill color button

5. Working with Sheets:
   - + button: add sheet
   - Right-click: rename/delete
   - Drag: reorder sheets

SECTION 03Formulas & Functions

Here are the most important Excel formulas and functions for beginners:

Function What It Does Example
SUM Adds numbers together =SUM(A1:A10)
AVERAGE Calculates the average =AVERAGE(B1:B10)
VLOOKUP Looks up values in a table =VLOOKUP(C2, A1:B10, 2, FALSE)
IF Conditional logic =IF(A1>100, "High", "Low")
COUNT Counts cells with numbers =COUNT(A1:A10)
MAX/MIN Finds highest/lowest value =MAX(A1:A10) 
VLOOKUP - The Most Important Excel Function:

Scenario: You have a list of Employee IDs and need to find their names.

Data Table (A1:B10):
ID    | Name
101   | Rahul Sharma
102   | Priya Patel
103   | Amit Singh
104   | Sneha Reddy

VLOOKUP Formula:
=VLOOKUP(102, A1:B10, 2, FALSE)
Result: Priya Patel

=VLOOKUP(105, A1:B10, 2, FALSE)
Result: #N/A (not found)

Syntax Explained:
VLOOKUP(lookup_value, table_array, col_index, range_lookup)
- lookup_value: what to search for
- table_array: where to search
- col_index: which column to return
- range_lookup: FALSE for exact match, TRUE for approximate

VLOOKUP Alternatives:
✅ XLOOKUP (Excel 365) - more flexible
✅ INDEX/MATCH - more powerful

Pro Tip: Always use FALSE for exact match
to avoid wrong results!
IF Function - Conditional Logic:

Basic IF:
=IF(A1 > 100, "High", "Low")
If A1 > 100 → "High", else → "Low"

IF with AND:
=IF(AND(A1 > 100, B1 > 50), "Pass", "Fail")
Pass only if both conditions are true

IF with OR:
=IF(OR(A1 > 100, B1 > 50), "Pass", "Fail")
Pass if either condition is true

Nested IF (Multiple Conditions):
=IF(A1 > 100, "Excellent",
    IF(A1 > 80, "Good",
        IF(A1 > 60, "Average", "Poor")))

Example: Student Grade Calculator
=IF(A1 >= 90, "A",
   IF(A1 >= 80, "B",
      IF(A1 >= 70, "C",
         IF(A1 >= 60, "D", "F"))))

IF with VLOOKUP:
=IF(ISNA(VLOOKUP(A1, B1:C10, 2, FALSE)),
    "Not Found",
    VLOOKUP(A1, B1:C10, 2, FALSE))

Pro Tip: Nested IFs work well for
simple logic. For complex logic, use IFS!

SECTION 07Interview Q&A — Excel Careers

Q1Why should I learn Excel in 2026?

Excel is the most essential business skill. It's used in 90% of companies, increases your salary by 20-30%, and opens doors to data analyst, business analyst, and financial analyst roles.

Q2What are the most important Excel functions for beginners?

SUM, AVERAGE, VLOOKUP, IF, SUMIF, COUNTIF, and Pivot Tables. These cover 80% of what you'll need in most jobs.

Q3How long does it take to learn Excel?

You can learn the basics in 1-2 weeks. It takes 2-3 months to become proficient with functions, Pivot Tables, and dashboards. Mastery takes 6-12 months of consistent practice.

Q4Can I get a job with Excel skills?

Yes! Data analyst, business analyst, financial analyst, and operations roles all require Excel skills. Entry-level roles start at ₹3-5 LPA and go up to ₹10-15 LPA with experience.

Q5What's the best way to practice Excel?

Download sample datasets from Kaggle or government websites, and practice building dashboards, Pivot Tables, and reports. Also, try to solve real problems from your work or daily life.

SECTION 09Frequently asked questions

What is Excel used for?

Excel is used for data organization, analysis, and visualization. It's used in finance, marketing, HR, operations, and almost every business function.

What are the basic Excel skills for beginners?

Navigation, data entry, formatting, basic formulas (SUM, AVERAGE), sorting, and filtering.

What is VLOOKUP in Excel?

VLOOKUP is a function that looks up a value in a table and returns a corresponding value from another column. It's one of the most important Excel functions.

What is a Pivot Table in Excel?

A Pivot Table is a tool that summarizes and analyzes large data sets instantly. It can group, filter, and aggregate data in seconds.

Can I learn Excel for free?

Yes! There are many free resources including YouTube tutorials, Microsoft's official documentation, and free practice platforms. Uncodemy also offers affordable, structured courses.
